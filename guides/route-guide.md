## 要点摘要

- 游戏的地图是按章节推进的，换图之后部分支线会永久失败。
- **一条通用规则**：接到支线就当场做到最近一步。
- **第一章：悲泣溪谷**：开端之地铃铛 → 圣母像裂缝。
- **隐藏区域（建议做完再走）**：塔顶用锁链拿营地外门钥匙 → 溪谷平原入口旁开门 → 远眺龙柱处铃铛，旁边宝箱拿锈蚀的龙形钥匙 → 附近房子找副官 → 回游戏最开始的地方用抓…
- **第二章：血色森林**：飞贼营地见虚空大人 → 血色森林、荒废官道铃铛 → 远眺庞镇之桥打花千笑。
- **第三章：陆家村**：梦醒之地铃铛 → 妖饰升级 → 过桥进村 → 隔墙见到蓝衣公子（暂时过不去）→ 老根头藏身处对话 → 打守门人拙壁。
- **第四章：庞镇**
- **东部主街**：秘密卸货处 → 废弃酒窖（拿辟火符）→ 火流星 → 景炀轩 → 市集 → 黄家宅邸前路口 → 斩骑 → 八卦阁（顶层拿楼顶钥匙见八卦童子）→ …
- **西部后街**：后街牌坊 → 武轩 → 找妙手小张 → 后街乘凉处 → 狭窄民居二楼 → 戏声缥缈的水塘（先存档；帮女弟子清敌后必须在她变异前击杀，否则不出记…
- **第五章：正道大营**：进图前把前几章欠的账清掉：圣母像裂缝的三面魔偶、悲泣溪谷与血色森林的龙柱、赤蛇屋与黑蛇屋的搜刮。
- **第六章：梅谷湖**：庞镇船坞 → 杀气塔顶层与地下 → 湖上 6 朵花 → 梅谷乐坊（修琵琶，和幻鬼对话，凡是需要琵琶的地方都探一遍）→ 杀气塔内部 → 陆家村浅…

# 发售前战斗系统预习：弹反、鬼步、煞气与多武器切换

> 本文来自[影之刃零资源站](https://yzrwiki.com/guides/combat-primer)，最新版本以站内页面为准。更新于 2026-07-18。

发售前战斗预习：弹反与蓝红光提示、鬼步反击、煞气管理、武器切换回气与检查点机制。

发售前先掌握已公开的战斗规则，首日上手会更顺。

一、把弹反当成核心动作，而不是可选技巧。敌人攻击带有可读的节奏与颜色提示，正确防守后的反击收益很高。想用纯闪避绕开系统，可能会错过本作最重要的攻防循环。

二、注意动画承诺。攻击动作虽然流畅，但出招后存在承诺感。也就是说，乱按会被 Boss 抓后摇；每一次起手都要判断距离、敌方前摇和自己当前武器的收招速度。

三、主武器与影之武装要分工。主武器负责稳定输出和连招，影之武装更适合作为打断、远程补足或爆发手段。正式版上线后，本站会按武器类型补具体连招表。

四、认颜色出反应，这是本作的「敌方语言」：**蓝光起手 = 强力技**，可以弹反，硬格挡会大量消耗煞气，成功弹反可衔接「鬼步」——一段带慢动作演出的瞬身位移，直接绕到反击位；**红光起手 = 杀招**，不可格挡不可弹反，必须用精准闪避应对，成功后同样可触发鬼步反击。弹反窗口比只狼略宽松，高难度下会收紧。

五、煞气管理贯穿全程。长按格挡与重击消耗[煞气](https://yzrwiki.com/wiki/sha-chi)，切换主武器可完全回气——双武器轮换是资源循环的核心，不是花活。打空敌方煞气即可处决。

六、两个降低挫败感的底层设计：检查点（铸钟/铃）回复状态但**不会刷新已清理的敌人**；难度分多档，默认难度强调学习曲线而非惩罚，最高难度「修罗」（暂译，Hellwalker）为解锁制，弹反窗口更严格。开发者明确表示不做「纯 Soulslike 式的挫败」。

七、不要把它简单当成 Soulslike。它更接近「只狼式攻防节奏 + 鬼泣式连段表达 + 武侠动作美术」。学习重点不是堆数值，而是掌握节奏、观察招式、选择反击窗口。

建议发售前观看夏末深度 State of Play。官方确认会集中展示战斗、Boss、世界与成长系统，那会是判断上手方式的关键节点。

## 常见问题

- **这个管理器和 Nexus 上的版本一样吗？** 本站镜像的是作者 GitHub Release 的 v1.5.6，文件哈希已核对。Nexus 原帖的下载页可能仍是旧版本，安装前请看页面上的版本号；两者不一致时，本页以 GitHub Release 为准并会注明。
- **需要先装 UE4SS 吗？** 管理器本身可以直接管理 Pak 类 MOD；如果某个 MOD 需要 UE4SS，仍要按那个 MOD 的作者说明先装对应版本的 UE4SS。管理器不能代替 MOD 的前置。
- **卸载管理器会把 MOD 一起删掉吗？** 不一定。先在各 MOD 条目里执行卸载或还原，再移除管理器。直接删除管理器文件夹可能留下已写入游戏目录的 Pak 文件。
